# OOP-Geven

A beginner-friendly collection of my JavaScript practice activities for Arrays and Object-Oriented Programming (OOP).

## Activities

### Arrays
- `array.js` — Practice using `pop()` and `filter()`.
- `unshift.js` — Practice adding items to an array using `unshift()`.

### Object-Oriented Programming
- `index.js` — Classes, constructors, methods, arrays, loops, and order totals.
- `inheritance.js` — Inheritance, `extends`, `super()`, and method overriding.
- `abstact.js` — An abstraction-style example using `SmartDevice` and `Smartphone`.

## How to Run

1. Install Node.js.
2. Open the repository folder in VS Code.
3. Open the terminal.
4. Run an activity using Node.js, for example:

   `node array.js`

Run each activity separately.

## Purpose

This repository documents my progress in learning JavaScript fundamentals, arrays, and Object-Oriented Programming.
